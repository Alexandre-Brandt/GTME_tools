## Let your coding agent build the integration

The Unipile MCP server gives your coding agent the whole Unipile API. It reads the contract, writes the LinkedIn, WhatsApp or email feature in your app and tests every call on your Development application.

### Add the server

One hosted URL for every channel and one scoped API key in the `X-API-KEY` header. Nothing to install.

`X-API-KEY`

### Describe the feature

Ask for an inbox, a sync or an outreach flow. The agent picks the right endpoints and reads their schema.

### Ship tested code

Calls run on your Development application first. In production, your users connect their own accounts through Hosted Auth.
