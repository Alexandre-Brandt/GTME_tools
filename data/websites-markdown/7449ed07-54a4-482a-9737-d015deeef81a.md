## Questions teams ask before switching.

### Do I have to rebuild my Clay tables?

No. Export the table as a CSV and import it into a sheet, or describe the workflow and let the agent add the columns. The rows you already enriched stay as they are.

### How is pipe0 different from Clay?

Clay made spreadsheet enrichment mainstream and has the larger template library. pipe0 gives you the same table workflow with tables up to 2M records, plus a full API and MCP server on the same engine, so agents can build and run the work too.[Full comparison](/compare/pipe0-vs-clay)

### How do you keep the data accurate?

A waterfall stops at the first answer, so the first provider decides accuracy. We benchmark providers against premium data and only add one when it finds data the others miss. Before you send, run email verification as its own step.[How we benchmark](/blog/cheapest-first-waterfall)

### Can pipe0 do CRM enrichment?

Yes, without a separate product. Put a sheet on a schedule: pull the accounts created yesterday from HubSpot, Salesforce, or Attio, enrich them, and write the results back to the CRM.[Schedules](/docs/sheets/schedules)

### Do I need a subscription?

No. Buy credits as you go and they never expire. Monthly plans lower the price per credit when your volume grows.[Pricing](/pricing)

### Can I take my data with me?

Always. Export any sheet to CSV at any size, write rows back to HubSpot, Salesforce, or Attio, or read them over the API.

### Can I use my existing provider contracts?

Yes. Store your own API key for a provider and pipe0 uses it instead of the managed connection, for a small platform fee per call.[Connections](/docs/connections)

### Do I need to be technical?

No. Most work starts as a sentence to the agent, and every column can be adjusted by hand. Engineers get the same engine as an API, a TypeScript SDK, and an MCP server.
