## Works with your AI tools

Use Happenstance inside ChatGPT and Claude, or build it into anything with the API.

mcp.json

```
{ "mcpServers": { "happenstance": { "type": "http",  "url": "https://happenstance.ai/mcp" } }}
```

```
curl -X POST "https://api.happenstance.ai/v1/search"  \ -H "Authorization: Bearer hpn_..."  \ -H "Content-Type: application/json"  \ -d '{ "text": "AI founders in SF, Stanford alum", "include_my_connections": true }'
```

```
$ brew tap happenstance-ai/tap $ brew  install happenstance $ hpn config set --api-key hpn_... $ hpn  search "VP Eng at fintech startup"
```
