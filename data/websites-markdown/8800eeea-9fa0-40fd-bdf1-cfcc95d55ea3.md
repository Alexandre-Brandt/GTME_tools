## One API for all web data

Take full control of search. Tune the index, pick the sources, set the freshness.

### Search

Web search built for AI applications. Get sourced, cited answers with full-text snippets from across the web. Fast, accurate, and grounded in real data from trusted sources.

[Get Started](https://app.linkup.so)[API docs](https://docs.linkup.so)

```
from linkup import LinkupClient client = LinkupClient( api_key="", # Or set the LINKUP_API_KEY environment variable ) # Perform a search query search_response = client.search( query="What is Microsoft 2024 revenue?", depth="standard", output_type="searchResults", ) print(search_response)
```
