## Make it your own

### Any language

VS Code supports JavaScript, TypeScript, HTML, and CSS out of the box. Language extensions add IntelliSense, linting, and debugging for Python, Java, C++, and many more. [Learn more about programming languages](https://code.visualstudio.com/docs/languages/overview)

### Any extension

Browse thousands of extensions in the Visual Studio Marketplace to add tools, integrations, and workflows. [Learn more about the Visual Studio Marketplace](https://code.visualstudio.com/docs/configure/extensions/extension-marketplace)

### Any environment

Use VS Code on Windows, macOS, or Linux, or open it in your browser at vscode.dev.
