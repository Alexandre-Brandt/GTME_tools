## Questions & answers

### What are Langdock Agents?

Langdock Agents are specialized chatbots that you can configure for specific use cases or documents. They behave like regular chat but keep saved context (documents + instructions), so you don’t need to repeat the setup every time.

### Why should I use an agent instead of regular chat?

Chat is ideal for quick, one‑off questions. Agents are better for recurring tasks, team workflows, or situations where you want to share a standardized setup with others.

### How can my team access internal agents?

Teams can use internal agents in three ways:

* Directly inside the Langdock platform
* Through the Langdock Slack app
* Through the Langdock Microsoft Teams app

### Do Langdock Agents support MCP (Model Context Protocol)?

Yes. Langdock provides full support for the MCP, enabling agents to interact with external tools and services through a standardized protocol. MCP integrates into Langdock’s existing integration architecture, so MCP servers behave just like other Langdock integrations and actions.    
‍  
Key features include:

* Automatic discovery of MCP tools exposed by a server
* MCP tools converted into Langdock actions with confirmation flows
* Support for multiple authentication methods (API key, OAuth 2.0, etc.)
