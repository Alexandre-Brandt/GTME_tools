## Frequently Asked Questions

Direct REST requests use an API key in the X-API-Key header. LeadMagic CLI uses secure browser sign-in through lm login; normal CLI workflows do not use a pasted LeadMagic API key. Hosted MCP uses OAuth in the AI client and does not accept static API keys in client configuration. Every interface uses the same LeadMagic account and credit balance.

Enrichment endpoints publish per-endpoint limits that are the same on every self-serve plan (Email Finder and Email Validation allow 600 requests per minute). The unmetered Search API is the one plan-based lane: a sustained 5 requests/second on Professional and 10 on Ultimate. Custom plans can carry higher limits, contact us.

LeadMagic covers 400M+ people profiles, 25M+ companies, and 46M+ open job postings. People, Company & Jobs Search is included from the Essential plan, and Professional and Ultimate run search with no credits per search, at 5 or 10 requests per second within a fair-use ceiling of 13,333 searches a day.

API errors and not-found lookups do not consume credits. Finder tools charge when data is found. Email Validation charges for definitive valid or invalid results; unknown results are free.

LeadMagic works with Clay, Apollo, Instantly, Smartlead, Bitscale, Salesforge, Zapier, Make, and custom workflows. MCP support brings the same data into Cursor, Claude, VS Code, Windsurf, and other AI clients.

LeadMagic is pay-as-you-go. Create an account, pick a plan starting at $99/mo, and get your API key immediately. Failed lookups don't consume credits, and you can cancel anytime.
