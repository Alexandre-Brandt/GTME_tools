## How the Agent Builder pricing works

### Agent Actions

Each workflow can include one or multiple agents. Per workflow run, every agent consumes actions – more for complex tasks, fewer for simple ones. Your only limit is the total monthly agent actions used across all runs.

## Pricing FAQs

### How does Weflow's pricing and packaging work?

![](https://cdn.prod.website-files.com/646f2301b8a3a4f0c46d13e6/646f3c2f8f2a6eda2f9416b6_faq-icon.svg)

Weflow uses modular, per-user pricing billed annually. You can buy any of three standalone products: [Activity & Contact Capture](https://www.weflow.ai/product/activity-capture) ($19/user/month), [Conversation Intelligence](https://www.weflow.ai/product/conversation-intelligence) ($39/user/month), and [Deal Intelligence & Forecasting](https://www.weflow.ai/product/deal-intelligence-forecasting) ($39/user/month); or choose [one bundle that combines them at a discount](https://www.weflow.ai/product/consolidation): Revenue AI Foundation ($49), Revenue AI Business ($59), and Revenue AI Enterprise ($79).

Pricing is flat-rate with no platform, implementation, or usage-based fees, and all plans require a minimum of 10 users. Multi-year discounts are available (10% for 2 years, 20% for 3 years). [Weflow's Agent Builder](https://www.weflow.ai/product/ai-workflows) is priced separately by agent-action volume (per workspace), with 25 actions included for free in every plan.

Different teams in your organization can be on different products, so you only pay for what each group needs.

### What are agent actions, and how does Weflow's Agent Builder pricing work?

![](https://cdn.prod.website-files.com/646f2301b8a3a4f0c46d13e6/646f3c2f8f2a6eda2f9416b6_faq-icon.svg)

**Total agent actions = Number of workflow executions × number of agents per workflow**

Agent actions are the unit of usage for [Weflow's Agent Builder,](https://www.weflow.ai/product/ai-workflows) which is priced per workspace depending on the total number of actions you need. Each workflow can contain one or more agents, and every agent consumes agent actions each time the workflow runs; more for complex tasks, fewer for simple ones.

As a guide, a Simple Agent executing one task uses 1 action, a Research Agent (pulls from multiple sources) can use 3 or more, and a Thinking Agent (multi-step reasoning) can use 5 or more. Every Weflow plan and bundle includes the Agent Builder Free tier (25 agent actions/month). To run more, you can select a paid tier: Growth ($299/mo, 500 actions), Scale ($999/mo, 2,500 actions), or Enterprise (custom volume).

Your only limit is the total monthly actions used across all runs.

The number of agent actions you need depends on how many workflows run across your workspace, how many agents each workflow contains, and how often those workflows execute, since every agent consumes actions on each run.
